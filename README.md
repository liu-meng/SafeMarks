# SafeMarks 使用说明

SafeMarks 是一个基于 Chrome Manifest V3 的本地加密收藏夹扩展。常规收藏会以密文形式保存在浏览器本地；如果在锁定状态下使用快速收藏，待写入条目会先临时明文保存在本地，待下次解锁后导入保险库。主密码不会明文落盘，只在当前浏览器会话内临时可用。

## 功能概览

- 使用主密码初始化加密保险库
- 将当前网页保存为加密收藏
- 通过右键菜单快速保存当前页面、链接或选中文本
- 在 popup 中搜索已保存的收藏
- 自动锁定或手动锁定当前会话
- 支持浏览器级快捷键打开 popup、快速收藏当前页、打开收藏管理和设置页
- 导入浏览器原生书签并处理重复项
- 导出加密备份、导出明文 JSON、导入加密备份
- 在版本更新后通过 popup 横幅查看更新日志

## 安装方式

本项目支持本地加载验证，也提供了用于应用商店提交的 ZIP 打包脚本。

### 1. 获取代码

将仓库下载或克隆到本地，例如：

```bash
git clone <your-repo-url>
cd SafeMarks
```

### 2. 在 Chrome 中安装

1. 打开 `chrome://extensions`
2. 打开右上角“开发者模式”
3. 点击“加载已解压的扩展程序”
4. 选择仓库根目录，也就是包含 `manifest.json` 的目录
5. 安装完成后，将 SafeMarks 固定到工具栏，便于后续使用

说明：

- 当前仓库没有前端构建步骤，安装时不需要执行 `npm install`
- 如果只是想验证核心逻辑，可以在本地运行测试，见本文末尾“开发验证”

### 3. 生成商店上传 ZIP

如果要提交到 Chrome Web Store 或 Edge Add-ons，可在仓库根目录执行：

```bash
npm run package:extension
```

生成结果会输出到 `dist/` 目录，例如：

```text
dist/safemarks-1.0.6.zip
```

仓库内还提供了发布所需的辅助文档：

- `docs/privacy-policy.md`：可直接托管为公开 HTTPS 隐私政策页面
- `docs/store-submission.md`：Chrome Web Store / Edge Add-ons 后台填写清单

## 首次使用

1. 点击浏览器工具栏中的 SafeMarks 图标，打开 popup
2. 在“先设置主密码”界面输入主密码，并确认一次
3. 选择自动锁定时间，当前支持 `1 / 5 / 15 / 30` 分钟，默认 `15` 分钟
4. 点击“创建保险库”

创建成功后，扩展会：

- 在本地生成加密保险库
- 自动解锁当前会话
- 进入已解锁状态，允许保存当前页面

注意：

- 主密码没有找回机制
- 如果忘记主密码，将无法解锁已有数据

## 日常使用

### 1. 解锁保险库

如果保险库已经创建，但当前会话处于锁定状态：

1. 点击 SafeMarks 图标
2. 输入主密码
3. 点击“解锁”

解锁后会恢复当前收藏列表，并开始自动锁定计时。

### 2. 保存当前页面

解锁后，popup 会尝试自动读取当前活动标签页的标题和 URL。

使用方式：

1. 打开想保存的网页
2. 点击 SafeMarks 图标
3. 在“添加当前页”区域确认标题和 URL
4. 点击“保存当前页”

限制：

- 只支持 `http` 和 `https` 页面
- `chrome://`、扩展页、浏览器内部页面等不会被保存

### 3. 搜索收藏

在已解锁状态下，可以直接在“搜索收藏”输入框里按以下内容过滤：

- 标题
- URL

### 4. 锁定保险库

有两种方式：

- 手动点击“立即锁定”
- 等待自动锁定超时

锁定后，当前会话内保存的临时密钥会被清除，需要重新输入主密码才能继续访问收藏。

### 5. 使用快捷键

SafeMarks 现在支持浏览器级快捷键：

- 打开 SafeMarks popup
- 快速收藏当前页
- 打开收藏管理页
- 打开设置页

说明：

- 默认建议按键会在浏览器安装时注册，实际是否生效取决于浏览器是否接受该组合键
- 如果某个命令显示“未分配”，请到 `chrome://extensions/shortcuts` 手动设置
- 设置页新增了“快捷键”区块，会直接显示当前绑定结果
- “快速收藏当前页”会先弹出一个专用页面，允许修改标题、URL 并选择已有目录或新增目录
- 在该页面提交后，如果当前已解锁，会直接写入保险库；如果当前锁定，会先未加密暂存在本地，等下次解锁后自动导入

## 设置页

popup 右上角和锁定页中都提供“设置”入口。设置页主要包含以下能力。

### 1. 修改自动锁定时间

可选值：

- 1 分钟
- 5 分钟
- 15 分钟
- 30 分钟

保存后：

- 新设置会写入本地保险库配置
- 如果当前已解锁，会话超时时间会同步更新

### 2. 导出加密备份

点击“导出加密 JSON”后，会下载当前保险库的密文备份文件。

特点：

- 不要求当前会话已解锁
- 适合做日常备份
- 恢复后仍然需要原主密码才能解锁

### 3. 导出明文 JSON

点击“导出明文 JSON”前提：

- 当前保险库已解锁

特点：

- 导出的内容可直接阅读
- 适合迁移或人工整理
- 存在明文泄露风险，导出后需要自行妥善保管

### 4. 导入加密备份

支持在 popup 锁定页或设置页导入加密 JSON。

导入后：

- 本地现有保险库会被新的加密备份覆盖
- 当前会话会立即锁定
- 需要使用该备份对应的原主密码重新解锁

### 5. 清空本地数据

点击“清空本地数据”会删除：

- 本地保存的密文保险库
- 当前会话密钥

该操作不可撤销。

### 6. 快捷键设置

设置页底部新增“快捷键”区块，可用于：

- 查看当前四个命令的实际快捷键绑定
- 一键打开浏览器的扩展快捷键设置页
- 在修改后回到 SafeMarks 设置页，立即确认最新绑定是否生效

## 数据与安全说明

- 收藏数据保存在 `chrome.storage.local`
- 当前会话密钥保存在 `chrome.storage.session`
- 自动锁定基于 `chrome.alarms`
- 保险库内容使用 Web Crypto API 加密
- 锁定状态下触发的“快速收藏”会先明文暂存在本地，待下次解锁后导入加密保险库并清除暂存

这意味着：

- 浏览器会话结束、超时或手动锁定后，需要重新输入主密码
- 常规收藏不会以明文形式持久化到本地存储；例外是锁定状态下待导入的快速收藏暂存

## 开发验证

如果你需要验证仓库中的核心加密逻辑，可以在项目根目录执行：

```bash
npm test
```

当前测试覆盖的主要是：

- Base64 编解码
- 保险库创建与解锁
- 错误密码校验
- 收藏密文的加解密往返
